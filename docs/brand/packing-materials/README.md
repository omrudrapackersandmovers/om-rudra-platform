# Om Rudra packing-material mockups

Created 6 October 2026 using the built-in image generation tool and the existing approved logo as reference. These are visual concepts, not supplier-ready print files. Generated mockups can vary in small lettering and logo details; use the approved SVG masters when preparing production artwork.

## Research

- [U-Haul packing supplies](https://www.uhaul.com/MovingSupplies/Packing-Supplies/): packing paper, stretch wrap, blankets, furniture pads and related supplies.
- [U-Haul moving checklist](https://www.uhaul.com/Publication.ashx?digest=BWvkMOPTZuQC3uMehBmK6g&id=3193779): boxes, mattress bags, tape, bubble wrap and packing paper.
- [Moving-material guide](https://alliaancemovers.in/moving-resources/packing-materials-packers-movers/): corrugated cartons and sheets, bubble wrap, EPE foam, stretch film, blankets, PP strapping and BOPP tape.

This research identifies common materials; it does not establish what Om Rudra currently purchases or uses.

## Branding approach

Direct printing: cartons, sealing tape, outer corrugated sheets, strapping and crates.
Labels or patches: inventory stickers, hardware bags, moving blankets and protective covers.
Removable sleeves or core labels: bubble wrap, foam, stretch film and packing paper. Contact cushioning remains unprinted.

Printing costs and methods are supplier-dependent. Some concepts show crimson plus charcoal, requiring two print colors; ask for a single-crimson alternative where cost matters. Handling arrows indicate package orientation, not lifting instructions.

## Production handoff

Use ../exports/lockup-horizontal.svg and ../exports/symbol-red.svg as the artwork sources, not the photographed logos in these PNGs.
Confirm stock sizes, board grade, tape width and repeat length, label dimensions, substrate, ink compatibility, print method, color proof, printable area, trim/bleed requirements and minimum order quantity with the supplier. Obtain actual carton dielines before creating final flat panels. Confirm phone number +91 7033488691 before printing. Do not invent load limits, certifications or recycling claims.
