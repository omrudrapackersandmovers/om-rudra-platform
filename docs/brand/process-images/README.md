# Moving-process image set

Seven coordinated illustrations of the moving process: survey, packing, loading, transport, unloading, unpacking and settling in. Generated with the built-in image tool, with plain charcoal workwear, neutral Indian settings and no company-name overlays. These illustrative scenes do not represent actual employees, vehicles, customer moves or owned premises.

PNG source masters and exact generation prompts in `manifest.json` are preserved here. App exports use versioned `-v2.webp` names and 320, 640, 960 and 1536 px responsive widths. Both apps receive the same set.

The public four-step flow uses survey, packing, transport and unpacking. The admin login slideshow uses transport, packing, loading, unpacking and settled scenes. Other existing process galleries use the appropriate new activity image. Earlier source images remain available for rollback.

Regenerate exports with `node docs/brand/process-images/export-processes.cjs` with `sharp` installed or accessible through `NODE_PATH`.
