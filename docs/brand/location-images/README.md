# Location image set

AI-generated illustrative regional landmark views, consistent with the natural daylight service and process imagery. No embedded company names, logos, location labels, or watermarks. These are destination illustrations, not photographs of company branches.

The manifest records each region, representative landmark, and exact generation prompt. PNG masters are retained here. Website delivery uses versioned WebP files with 320, 640, 960, and 1536 pixel variants. Run `node docs/brand/location-images/export-locations.cjs` with Sharp available to regenerate the exports.
